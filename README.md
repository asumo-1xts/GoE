## 概要

チャットアプリにおいてEnterキーによる誤送信を防ぐための常駐アプリです。

| 操作       | Before            | After            |
| ---------- | ----------------- | ---------------- |
| 変換を確定 | `Enter`           | `Enter`          |
| 改行       | `Shift` + `Enter` | `Enter`          |
| 送信       | `Enter`           | `Ctrl` + `Enter` |

## 対応環境

### OS

- Windows 11

### 日本語入力ツール

- Microsoft IME

### デフォルト対応アプリ
